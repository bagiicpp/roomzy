# roomzy.

**Smarter renting starts here.**

Roomzy is an ML-powered mobile application designed to help students make informed decisions when searching for rental apartments.

The application uses a custom-trained machine learning model to estimate rental prices based on historical market data and property characteristics. It also evaluates apartment locations, nearby amenities, and individual preferences to provide personalized apartment ratings.

## Key Features

- **ML-Powered Price Prediction** — Estimate rental prices using regression models trained on historical housing data.
- **Apartment Scoring** — Rate apartments from 0–10 based on affordability, location, size, and amenities.
- **Location Analysis** — Evaluate proximity to universities, public transport, grocery stores, and other essential services.
- **Apartment Comparison** — Save and compare multiple rental listings.
- **Model Explainability** — Understand which factors influence predicted rental prices.

## Tech Stack

- **Mobile:** React Native, Expo, TypeScript
- **Backend:** Python, FastAPI
- **Machine Learning:** scikit-learn, XGBoost
- **Database:** SQLite
- **Maps & Geolocation:** OpenStreetMap APIs
